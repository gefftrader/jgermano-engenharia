## Sobre o sistema

Arquivo único, sem instalação e sem servidor. Os dados ficam no
navegador de quem abre, e o backup sai pelo botão de ajuda no topo.

Toda operação passa por uma camada de ações com validação, e é a mesma
camada que a secretária usa. Quer dizer: o que você faz pelo botão e o
que você pede em português dão exatamente no mesmo lugar, com as mesmas
travas. Pergunta nunca escreve, apagar pede confirmação mostrando o
estrago, e o alvo tem que estar colado no verbo.

O trilho da obra tem seis posições, de 0 a 5: orçamento, aguardando
aprovação de crédito, início, execução, final de obra e pós-obra.
Pausada e concluída ficam fora do trilho, porque não são etapa, são
situação.

## Uma palavra sobre os dados

O sistema abre com os dados da operação real da JGermano. Quem for usar
de verdade edita direto na tela, e a partir daí o que vale é o que está
no navegador.
